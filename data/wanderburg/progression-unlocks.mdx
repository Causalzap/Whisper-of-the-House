<h2 id="how-progression-works">
  What actually carries forward in Wanderburg
</h2>

The early game becomes much easier to read once I stop treating every new icon as the same kind of progression.

A Land objective can open another part of the overworld. Silver can turn an already unlocked module, Crew, Captain, or Artifact into a permanent starting option. Other objectives unlock the item in the first place. Meanwhile the castle I build inside a run — its levels, Gold, temporary upgrades, size, and ridiculous damage numbers — disappears when that run is over.

Those layers overlap constantly, which is why a run can feel productive without immediately changing the next loadout. I may finish a biome gate, gain Silver, push a module toward its permanent unlock condition, and still return to a familiar set of starting choices.

The question I use between runs is therefore not simply **“What did I unlock?”** It is **“Which part of the account changed?”**

If a new Land appeared, that is overworld progression. If a shop entry became available, the condition is finished but the purchase may still need Silver. If the upgrade pool keeps showing the same handful of modules, I usually have more permanent module work left to do.

<h2 id="green-plains">
  Green Plains is a four-boss gate, not a one-boss tutorial
</h2>

Green Plains gives several useful objectives at once:

- defeat the full boss sequence to open the next Land routes;
- consume **100 units in one run** for **500 Silver**;
- destroy **20 Rams overall** for **1,000 Silver**;
- destroy **5 Harvesters overall** for **2,500 Silver**.

The important distinction is the boss condition. Beating the first boss grows the current castle, but it does not finish the Green Plains map gate. I need the complete sequence.

That makes the first few runs less about farming everything visible and more about reaching one run that can remain functional long enough to finish all four bosses. A mediocre build that kills boss one and falls apart afterward is still telling me something useful: progression is no longer blocked by finding the right map objective; the current account simply cannot carry enough power or survivability through the whole route yet.

At that point I fix the run rather than search for another hidden gate. The <Link href="/wanderburg/bosses">Wanderburg Boss Guide</Link> covers the four fights themselves, while the <Link href="/wanderburg/best-builds">best builds guide</Link> handles the module combinations that need to survive between them.

The side objectives are worth taking when they fit naturally into the clear. I will detour for the fifth Harvester if the counter is almost finished; I will not ruin a strong boss attempt just because a distant target would add one more point to a permanent objective.

<h2 id="where-to-go-next">
  Golden Dunes or Meadows after Green Plains?
</h2>

Once Green Plains is finished, the route stops being a single straight line. **Golden Dunes and Meadows can both matter, but they solve different account goals.**

I go to **Golden Dunes when Spiderburg is the next thing I want to change about the account**. Its complete boss objective leads into that vehicle unlock.

I take **Meadows when I want to keep extending the overworld toward Waving Fields** or when its own objectives are the better source of permanent progress at that moment.

Neither choice makes the other route obsolete. The useful way to think about the map is as a set of permanent objectives rather than a campaign line that must always be followed in one exact order. If an older Land has a nearly finished Silver objective, a module condition I can complete there comfortably, or a safer environment for testing a new starting setup, returning is productive. Repeating it only because it is familiar usually is not.

Later progression keeps using the same idea. Complete boss sets matter more than isolated victories, and the objective panel is more reliable than trying to infer the next gate from the physical layout of the overworld.

<h2 id="silver">
  Spend Silver on the next run, not on the collection screen
</h2>

Silver is scarce enough early that one exciting purchase can delay several useful ones.

The spending mistake I try to avoid is buying something because it looks strong in isolation while the starting loadout still has an obvious hole. A Captain does not help much if the chassis cannot fill an important slot. An Artifact does not repair a build whose main damage module is still missing. Owning many options also does not automatically produce a coherent starting setup.

My first purchases usually follow this order:

1. **the module needed to make a real starting build work;**
2. **a Crew that directly strengthens what that build already does;**
3. **a Captain that fixes a recurring problem rather than creating a new one;**
4. **Artifacts and sidegrades once the account can already start runs cleanly.**

That is a priority, not a rigid shopping list. If a particular unlock creates a second usable build immediately, I am happy to take it earlier.

Boss progress now helps this economy more directly because boss tombstones can be collected for Silver. That makes complete runs attractive for two reasons at once: they move Land progression and leave more permanent currency behind.

Captain purchases deserve extra restraint because their bonuses often come with meaningful drawbacks. I choose them after I understand why my runs are ending rather than buying the highest letter on a list. The current tradeoffs are covered in the <Link href="/wanderburg/captains-tier-list">Wanderburg Captains Tier List</Link>.

<h2 id="rerolls">
  Unlocking more Modules and Artifacts now improves rerolls
</h2>

Permanent collection size used to be easy to dismiss once I had the handful of pieces needed for my favorite build. That is no longer how I value it.

The current progression system adds:

**every 6 unlocked Modules → +1 New Module Reroll**

**every 6 unlocked Artifacts → +1 Artifact Reroll**

This changes the value of purchases near a six-item breakpoint.

Suppose my core build is already functional and I have five unlocked Modules toward the next reroll. A sixth useful unlock is doing two jobs: it adds another permanent option and improves my ability to reject a bad Module offer during future runs. The same logic applies to Artifacts.

I still do not buy random junk merely to inflate the collection. A larger pool can dilute the chance of seeing a specific piece, so the better progression is **useful breadth** — unlocking things I can genuinely build around while taking advantage of the reroll milestone attached to the collection.

That also makes rerolls part of the answer when the early upgrade pool feels stubborn. Before spending them freely on minor differences, I save them for offers where none of the available choices advances the build I am actually making.

<h2 id="permanent-module-unlocks">
  Module objectives are worth forcing only after a run is safe
</h2>

Several important modules begin behind conditions completed during normal play rather than a direct Silver purchase.

The permanent unlock objectives I use include:

- **Archer Crew level 5 → Archer Tower**
- **Mine Layer level 10 → Turret Layer**
- **Side Cannons level 10 → Front Cannon**
- **destroy 100 Health Boxes overall → Repair Crew**
- **consume 300 Cows → Catapult**
- **Ram level 10 → Side Arms**

I do not chase these milestones with the same urgency throughout a run.

If Mine Layer is level 7 and the castle is barely keeping up with enemy health, forcing three more Mine levels can destroy the run before the permanent reward is reached. If the build is already comfortably clearing everything and the boss timer is no longer threatening, those same three levels become cheap permanent progress.

That is the moment I start bending the upgrade choices toward unlock conditions.

There is another distinction that matters after the notification appears: **unlocking an item and owning it are not always the same step**. Several permanent options become available in the loadout/shop after their condition is completed and still require Silver before I can equip them as a starting choice.

So when an unlock fires and the next run still cannot use the item, I check the permanent purchase screen before repeating the condition.

<h2 id="same-modules">
  Why the same Modules keep appearing
</h2>

Early Wanderburg runs can feel unusually repetitive because the account genuinely does not contain very many permanent options yet.

Cannon, Ram, Top Mortar, Mine Layer, and a small starting Crew pool can dominate the offers for several runs. Moving from Green Plains into another Land does not automatically replace that set with a fresh arsenal.

Variety arrives from the permanent layer. Archer Tower, Turret Layer, Front Cannon, Barracks, Ballistas, Mages, Catapult, Side Arms, and later combinations become relevant only after their requirements have been completed and the necessary purchases have been made.

That is why changing Lands is a poor fix for a repetitive loadout. I get more out of checking which module condition is close to completion and which purchase would create a genuinely different starting plan.

The new reroll milestones help here too, but rerolls do not replace permanent progression. Rolling the same shallow pool again is still a shallow pool.

<h2 id="overtime">
  Overtime is worthwhile when the finished castle can keep producing
</h2>

A normal win presents a different kind of progression decision: leave with what I earned, or continue with the castle I already spent the whole run building.

One Meadows run lasted nearly **20 minutes** and ended above **3,000 Silver**. Overtime contributed **570 Silver**, with Gold conversion, collected Silver, quest rewards, and the Land's **1.2x Silver factor** making up the rest.

That is the kind of castle I continue with: enough HP to absorb an ugly exchange, enough movement to avoid getting pinned, and enough damage that normal threats are still dying without every active ability being spent at once.

A weak victory is different. If the fourth boss leaves the castle barely mobile and one bad group can erase the remaining health, restarting can produce more permanent progress per minute than squeezing a short Overtime out of a build that is already finished.

I also look at what the run was supposed to buy. If I entered needing 1,500 Silver for a specific purchase and already have it, there is nothing wrong with leaving. Overtime is valuable because it extends a productive castle; it is not a tax attached to every win.

<GuideCallout title="Gold and Silver do different jobs">
Gold develops the castle that exists right now. Silver survives the run and changes future loadouts. A spectacular temporary build is useful only while it is alive; a permanent module, Crew, Captain, Artifact, vehicle, or reroll improvement affects runs that have not started yet.
</GuideCallout>

Once it is running, Spiderburg also changes how I value movement. Its smaller, more maneuverable early form can escape positions that feel much more awkward in a larger conventional castle, although later growth can still turn mobility back into a problem. That belongs to the build decision rather than another hidden progression step.

<h2 id="later-progression">
  Later progression still rewards complete boss routes
</h2>

The structure established in Green Plains continues after the first branch. Meadows can push the overworld toward **Waving Fields**, Golden Dunes leads into the Spiderburg route, and later objectives again care about completing the relevant boss sequence rather than collecting one isolated boss kill.

I follow the objective panel rather than assuming that physical map position implies the next requirement.

This becomes especially useful once several Lands are open at the same time. One may advance the overworld, another may offer the Silver objective I am close to finishing, and a third may simply be a better place to test a new vehicle. All three can be useful without being the same kind of progress.

A boss kill is therefore meaningful only in context. If the Land objective still needs the complete set, I continue. If the gate has already opened, another clear is useful because of Silver, unlock conditions, achievements, or testing — not because the game is secretly waiting for the same progression trigger again.

<h2 id="progression-stuck">
  When progression looks stuck, check which layer is actually blocked
</h2>

Most of the confusing stops I encounter fall into one of four categories.

**The next Land is still locked:** I check the current biome objective and whether its complete boss requirement has actually been satisfied.

**An item says unlocked but cannot be equipped:** I check whether it still needs a permanent Silver purchase.

**A vehicle is unlocked but the run cannot start:** I check whether the chassis requires a module layout my account cannot currently fill.

**The correct Land is open but I cannot beat it:** that is no longer a progression puzzle. The account needs a stronger build, better movement, or a more suitable vehicle setup.

Keeping those problems separate saves a lot of unnecessary repeat runs.

The <Link href="/wanderburg">Wanderburg guide hub</Link> connects the map, build, Captain, vehicle, and boss routes. If the correct objective is already available and the blocker is simply surviving its bosses, go straight to the <Link href="/wanderburg/bosses">Boss Guide</Link>.

<h2 id="next-objective">
  What I do before starting the next run
</h2>

Before Green Plains is finished, I do not overthink the decision: the next useful run is another attempt at the complete boss gate.

After the map branches, I check three things before pressing Start.

First, **which Land objective changes the account if I finish it?** That may be Golden Dunes for Spiderburg or Meadows for the next overworld branch.

Second, **which permanent unlock is already close?** A Mine Layer sitting one good run away from its level requirement can be more valuable than wandering into another Land without a specific goal.

Third, **what does the Silver balance actually buy?** If I already unlocked the piece that fixes the starting loadout, funding that purchase may matter more than opening another option I cannot yet use.

The reroll breakpoints add one more useful tiebreaker. When two purchases are both relevant, the one that becomes my sixth Module or sixth Artifact can improve future drafts at the same time.

That leaves the progression loop fairly simple without making every run identical:

**finish a meaningful gate, turn its rewards into permanent options, then start the next run with an account that can do something it could not do before.**

<h2 id="blocked-by-corruption">
  If a path says it is blocked by corruption, I leave it alone
</h2>

This was one of the easiest progression blockers for me to overthink.

I reach a road that clearly looks usable, walk up to the corruption, and get a
message saying the path is blocked.

My first instinct is to search nearby.

Maybe there is a lever.

Maybe an NPC opens it.

Maybe I missed another entrance.

That is usually wasted time.

The message itself tells me what controls the route:

**collect enough Ova → progress the Gloom Siphon → gain the vapor needed to
cleanse corruption.**

So I treat corruption as a **story gate**.

I remember the route and move on.

I do not:

- attack the corruption with different weapons;
- search for a pressure plate;
- buy a location hint hoping it reveals another door;
- circle the area looking for a rear entrance;
- assume the route is bugged.

Mortal Shell 2 has plenty of genuine hidden paths.

An explicit corruption message is not one of the places where I spend time
secret-hunting.

<h2 id="unblemished-ova">
  Unblemished Ova are progression items, not ordinary collectibles
</h2>

Once I reach Marrow Keep, the role of the Ova becomes much clearer.

The **Unblemished Ova** were stolen, and recovering them is part of the main
progression loop.

That changes how I prioritize exploration.

If I have a choice between:

**another optional side room**

and:

**an objective that can recover an Ova**

I usually take the Ova when progression is my goal.

A weapon, Shell, Tarstone, or Sidearm can improve the build I already have.

An Ova can change **which parts of the world I am allowed to enter**.

That makes it a different class of reward.

I still take useful detours when they are cheap.

What I stop doing is spending an hour collecting optional upgrades while
several major routes remain closed by the same progression gate.

The **Gloom Siphon** is the system that turns recovered Ova into larger
progression changes, and **Milos** is the Ovum Keeper tied to this part of the

That second point is easy to underestimate.

If I keep exploring without checking Marrow Keep, I can end up revisiting
blocked routes before I have actually changed the progression state that
controls them.

<h2 id="when-i-prioritize-ova">
  When I prioritize Ova over weapons, Shells, and dungeons
</h2>

I do not abandon every optional activity the moment an Ova objective appears.

If my current region is open and my build is working, I still take useful
weapons, Shells, Tarstones, Sidearms, and dungeons when they fit naturally into

My priority changes when **progression itself starts closing around me**.

If I have reached several routes that all end in corruption, another optional

<h2 id="methers-breath-vs-pulse">
  Mether's Breath and Mether's Pulse are different systems
</h2>

The names are similar enough that I initially treated them as if they were part
of the same unlock.

They are not.

For this progression problem, I care about **Mether's Breath**.

That is the utility tied to:

- beacon fast travel;
- corruption removal;
- reopening previously blocked routes.

**Mether's Pulse** appears separately in other parts of the game's upgrades and
systems.

So if I find something that improves Mether's Pulse, I do not assume I have
just solved a corruption gate.

When the problem is:

**"This path is blocked by corruption."**

the progression check I care about is:

**Do I have Mether's Breath yet?**

That keeps me from spending resources on the wrong system while waiting for a
wall that was never connected to that upgrade.

<h2 id="what-i-do-when-stuck">
  What I check when every useful route seems blocked
</h2>

When several directions appear to end in corruption, I use the same order every
time.

**First, I stop revisiting the barriers themselves.**

The corruption is the symptom, not the next objective.

**Second, I check my Ova progression.**

If I have recovered an Unblemished Ova or completed an Ova-related objective, I
return to Marrow Keep and check the Gloom Siphon.

**Third, I check whether Mether's Breath is already available.**

If it is, then the problem may simply be that I have not returned to the old
route after changing my progression state.

**Only then do I treat the problem as navigation.**

That order prevents the loop I fell into early:

**blocked road → search around road → leave → return to same road → search the
same walls again.**

The solution to a corruption gate is usually not hiding beside the corruption.

It is somewhere else in the progression loop.

<h2 id="why-ova-matters">
  The rule I use for Ova progression
</h2>

Before Mether's Breath, Mortal Shell 2 feels much more segmented.

I can see roads I cannot use.

I can reach corruption I cannot clear.

And revisiting distant places costs more time.

Ova progression gradually changes all three.

That is why I never think of the Unblemished Ova as another collectible set.

For me, the practical loop is:

**recover Ova → return to the Gloom Siphon → unlock more traversal → revisit the
routes that were deliberately left behind.**

So whenever I see the corruption message, I no longer ask:

**What did I miss beside this wall?**

I ask:

**Has my Ova progression changed enough for this wall to matter yet?**

If the answer is no, I leave.

That is usually the fastest route forward.

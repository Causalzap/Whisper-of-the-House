My most useful first-Prestige lesson came from a 26-point reset.

The total was enough to unlock Signal Decryption, Tasks and Auto Explore, but I
finished one point short of another repair upgrade I wanted. One nearby Spire
would have improved every later repair route. Searching the unexplored map for
several more Spires would only have delayed permanent progress.

That run gave me the rule I still use:

> repair one more visible Spire when it crosses a known Augment cost; reset when
> I would need to wander for an unknown amount of progress.

I do not judge a run by how many machines remain available to upgrade. I judge
it by whether the next temporary purchase is stronger than the permanent
Augment I can already afford.

This guide covers:

- fast and balanced first-Prestige routes;
- what System Reset removes;
- the best early Augments;
- the upgrades I delay;
- when another Spire, Reactor or achievement is worth waiting for;
- how my priorities change on later Prestiges.

<h2 id="fast-or-balanced-reset">Choose a Four-Point Reset or a 20–30-Point First Prestige</h2>

There is no single correct first-Prestige total.

The map, item drops, Energy production and number of nearby Spires change how
quickly the current run can earn permanent value. I use two routes.

### Take the fast reset at about four points

I use the fast route when:

- Navigation and Mobility are working;
- I have repaired the first Spire;
- ordinary POIs are no longer opening new systems;
- another Body expansion only makes the current machine larger;
- the next permanent improvement is already affordable.

One tested Reset preview showed:

- **3 Augment Points from Energy**;
- **1 Augment Point from repairs**;
- one repaired Spire;
- four completed achievements providing a **2% achievement bonus**;
- a final total of **4 points**.

Four points are useful when the alternative is spending another long period on
temporary equipment.

They are not enough to buy all three core progression unlocks in the captured
tree:

- Signal Decryption cost **1 point**;
- Tasks cost **4 points**;
- Auto Explore cost **6 points**.

Those three alone total 11 points before prerequisites or supporting upgrades.

I use the four-point route to improve the second start and begin opening the
path toward those systems.

### Stay for 20–30 points when repairs remain efficient

I extend the first run when:

- more Spires are already visible;
- the machine can repair them without a major rebuild;
- one nearby achievement is almost complete;
- another repair crosses a specific Augment cost;
- Energy and resource production remain stable while moving.

Around 20–30 points, the first Prestige can become a complete progression
package rather than a small restart bonus.

My preferred package includes:

- Signal Decryption;
- Tasks;
- Auto Explore;
- one achievement-related improvement when points remain;
- Repair Speed or repair rewards when the exact total allows it.

I stop extending the run when the next useful point requires searching dark map
areas, rebuilding the entire resource chain or waiting only for temporary
production.

<h2 id="what-system-reset-removes">Know What System Reset Removes</h2>

I treat System Reset as a complete wipe of the current machine.

The confirmation screen warns that I will lose:

- Body upgrades;
- Mobility progress;
- Internal Wiring upgrades;
- items and installed equipment;
- stored resources;
- Trader Reputation.

That means I do not spend another hour creating a perfect Body Grid immediately
before resetting.

The Batteries, Furnaces, storage containers and carefully arranged Wiring do not
move into the next run.

The permanent value comes from:

- purchased Augments;
- completed achievements;
- Terminal progression;
- knowledge of the route;
- faster future access to Traders, repairs and automation.

Before confirming, I perform one final check:

1. open the System Reset preview;
2. note the point sources;
3. identify the exact Augment I want next;
4. compare its cost with my current total;
5. check whether one nearby action reaches it;
6. reset if the remaining work is only temporary expansion.

I do not stay merely because the current layout still has empty tiles.

- Signal Decryption;

> If one currently visible Spire completes the purchase package, I repair it. If
> I need to explore blindly and hope to find another one, I reset.

This keeps the balanced route from becoming an endless first run.

<h2 id="best-first-augments">Buy the Augments That Open New Progression First</h2>

I buy early Augments by the problem they remove.

A small statistical increase can be useful, but access to a new system usually
changes the next run more.

### 1. Signal Decryption

Signal Decryption cost **1 point** in the captured tree.

It causes Spire signals to be decrypted after the Navigation Computer has been
repaired.

That turns a repaired Spire into a route-planning tool. I can reveal Trader
locations and make the next run purposeful instead of wandering between ordinary
POIs.

I buy it before investing heavily in map convenience.

### 2. Tasks

Tasks cost **4 points** in the captured tree.

The Augment unlocks the ability to accept and complete work for Traders.

Without Tasks:

- buying and selling does not create the progression loop I need;
- a Transponder cannot mark a useful Task destination;
- visiting every Trader may trigger contact achievements but does not build a
  reliable Reputation route.

I buy Tasks before Trader-stock upgrades, Reputation retention or Task
multipliers.

### 3. Auto Explore

Auto Explore cost **6 points** in the captured tree.

It removes repeated manual map clicks and later supports:

- resource collection;
- Spire hunting;
- exploration achievements;
- cumulative travel;
- automated repair routes.

I still need positive Energy, useful Mobility, storage and a viable resource
chain. Auto Explore automates a working machine; it does not repair an unstable
one.

### 4. Achievement bonus

Completed achievements already contribute to System Reset.

The related Augment improves the return from progress I am making anyway:
Energy, capacity, item upgrades, travel, exploration and repairs.

I buy an early level when it fits after the core access route.

I do not sacrifice Tasks or Auto Explore for it.

### 5. Repair Speed

Repair Speed reduces the wait for Spires, Reactors and Terminals.

I buy it when the current repair timer is preventing active progress.

It improves the current run immediately, but it does not increase the number of
points earned from each completed repair.

### 6. Repair Augment Points

This branch increases the points gained from repaired Spires and Reactors.

It is the stronger long-term investment when I already have a reliable repair
route.

Repair Speed lets me finish more repairs in the same time. Repair Augment Points
makes every completed repair worth more at the next Reset.

I choose between them based on the current bottleneck:

- waiting too long → Repair Speed;
- repairs are already fast but Reset rewards remain small → Repair Augment
  Points.

<h2 id="augments-i-delay">Delay Augments That Arrive Before Their Supporting Systems</h2>

Some Augments are powerful but poor first purchases.

### Replicator

The Replicator cost **40 points** in the tested Augment tree.

That places it beyond a four-point reset and outside many 20–30-point first
Prestiges.

Unlocking it also does not provide every recipe automatically. I still need:

- Trader access;
- Lab keys;
- Lab progression;
- Blueprints;
- crafting components;
- stable Energy and resource production.

I buy the Replicator when I can name the exact hard-to-find machine I intend to
craft.

I do not buy it simply because crafting sounds powerful.

### Trader stock and Reputation retention

Trader Stock Amount can be inexpensive. One captured first level cost **3
points** and increased stock by 50% for resources and doubled item availability.

That is useful only when Trader stock is already limiting the run.

I do not buy it before Tasks and reliable Trader access.

Known Reputation is much more expensive. A captured level cost **50 points** to
increase the retained starting Reputation from level 1 to level 2.

I delay it until:

- I am completing Tasks efficiently;
- higher Trader tiers unlock equipment I repeatedly need;
- rebuilding Reputation after every Prestige has become a measurable delay.

### Offline Progress

Offline Progress is valuable when I close the game for long periods.

It is weaker for me when I leave the game running or interact with it throughout
the day.

I buy it for my actual schedule, not merely because IDLE_DIRECTIVE is an idle
game.

### Manual collection and small convenience nodes

Click Power, minor starting capacity and similar nodes can smooth the opening.

I spend on them after the current progression package is complete, or when the
remaining points cannot reach a more important branch.

I do not let cheap nodes consume the points required for Tasks, Auto Explore or
repair automation.

<h2 id="delay-for-achievement">Delay Prestige Only for a Nearby Achievement</h2>

Achievements improve the Reset calculation, but not every achievement visible
in the list belongs to the current run.

I wait when the requirement is already close and can be completed without
changing the machine's purpose.

Good examples are:

- one larger Battery reaches the next capacity threshold;
- one inexpensive item reaches the next upgrade milestone;
- one visible Spire completes the next repair count;
- one short trip crosses an exploration or travel threshold;
- an available efficiency boost immediately triggers the next achievement.

Energy Capacity achievements check installed capacity rather than current
charge. That can make a temporary Battery rearrangement worthwhile immediately
before Reset.

<h2 id="spires-reactors-terminals">Choose Spires Before Expensive Reactors</h2>

I do not treat every repair target as equal.

### Spires are my early Prestige route

Spires are the practical source of early repair progress because they:

- repair faster than Reactors;
- support Signal Decryption;
- reveal important map locations;
- contribute to the repair count;
- provide Augment Points at Reset.

I repair another Spire when it is visible and crosses a known purchase cost.

After Auto Explore and Auto Repair are available, I use Spires as the first
repeatable automated repair target.

### Reactors need a working resource economy

One tested early Reactor required:

- **9,000 Metal**;
- **100 Rare Metal**;
- **18,000 Biomass**;
- approximately **15 minutes** of repair time;
- additional Energy to activate it.

Before stronger repair-reward Augments, that Reactor contributed **3 Augment
Points**.

I repair it when:

- the Metal, Rare Metal and Biomass chains are already operating;
- the resource payment does not stop Mobility or another repair;
- three additional points unlock a specific Augment;
- the current run will continue long enough to rebuild the buffer.

I leave it for the next run when:

- it drains every storage container;
- Rare Metal is still needed for essential upgrades;
- Biomass consumption threatens the main generator;
- the 15-minute wait creates no other useful progress;
- one or more faster Spires remain available.

Repair-reward Augments eventually make Reactors much more attractive. Early on,
the theoretical reward does not matter if the machine cannot sustain the bill.

### Terminal repairs should not hold the Prestige hostage

Terminal progression spans multiple Prestiges.

I do not remain parked beside a Terminal only to watch its timer when the current
Augment package is already ready.

I begin the repair when the machine can afford it, then continue the Reset cycle
according to the current save's progression.

<h2 id="later-prestige-priorities">Shift From Access to Scale on Later Prestiges</h2>

The first Prestige opens systems.

The second and third Prestiges make those systems efficient.

My later order usually becomes:

1. Auto Repair;
2. Repair Speed;
3. more Augment Points from repairs;
4. resource density and raw-material multipliers;
5. Replicator access, speed and slots;
6. Trader Reputation gain and retention;
7. stronger starting Mobility and Sensor Range.

A captured later tree shows how costs and returns scale.

### Repair Augment Points

At rank 3 of 8, the next level cost **80 points**.

It changed the rewards from:

- Spire: **7 → 9 Augment Points**;
- Reactor: **15 → 20 Augment Points**.

That is a major long-term increase when Auto Repair is already completing many
POIs.

### Repair Speed

At rank 2 of 6, the next level cost **32 points**.

The displayed repair times changed from:

- Spire: **2:24 → 2:06**;
- Reactor: **12:00 → 10:30**;
- Terminal: **2:24:00 → 2:06:00**.

I buy that level when repair time is the limiting factor.

### Replicator upgrades

A captured Extra Replicator Slots level cost **30 points** and increased slots
from three to four.

A captured Replicator Speed level also cost **30 points** and reduced crafting
time by 20%.

I buy slots when confirmed recipes are waiting in a queue.

I buy speed when one long recipe is delaying the active build.

### Resource and Trader nodes

The same later tree included:

- Trader Stock Amount at **3 points**;
- Resource Density at **8 points** for 30% more POI resources;
- Raw Material Yield at **20 points** for a 2× raw-material multiplier;
- Reputation Gain at **24 points** for the next Task Reputation multiplier;
- Known Reputation at **50 points** for a higher retained starting level.

Cheap does not always mean early priority.

Trader Stock at three points can be a good leftover purchase. Known Reputation
at 50 points requires a run that actually benefits from persistent Trader
progress.

At one later Reset, I had approximately **560 points** to distribute. Even that
total could not buy every desirable rank.

The purpose of a later Prestige is still to remove the next run's bottleneck,
not to fill the entire tree.

<h2 id="restart-after-prestige">Restart With One Objective, Not the Old Layout</h2>

After confirming Augments, I do not recreate the previous Body Grid tile for
tile.

My restart sequence is:

1. run Diagnostics;
2. reboot the Scanners;
3. start the Repair Protocol;
4. Scavenge immediately;
5. install enough temporary power to become Energy-positive;
6. repair the Recycler;
7. restore Navigation;
8. upgrade Mobility;
9. return to a Spire;
10. use the newly purchased permanent system.

The second opening should reflect the Augments I bought.

If I purchased more Scavenge results, I should find useful equipment faster.

If I purchased Starting Body Size, I should fit a functional setup with less
rearranging.

If I purchased Signal Decryption, the first repaired Spire should reveal a real
route.

If I purchased Tasks, I should visit a Trader with a Task plan rather than buy
random stock.

If I purchased Auto Explore, I should first build enough Energy, Mobility,
storage and processing to sustain it.

If I purchased Auto Repair, I begin with Spires before adding expensive
Reactors.

Every new run gets one primary objective:

- complete Trader Tasks;
- automate Metal or Biomass;
- create a repeatable Spire route;
- unlock and use the Replicator;
- complete one difficult achievement;
- advance Terminal progression.

I reset again when another temporary machine upgrade is worth less than the
permanent Augment package already waiting.

The loop remains:

> build only what the current objective needs → repair the POIs that fund the
> next breakpoint → take one cheap nearby achievement → reset before optimizing
> temporary equipment becomes the objective.

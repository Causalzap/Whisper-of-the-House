<h2 id="hospital-route">The Beaulieu Hospital route I use</h2>

Hospital became much easier once I stopped treating every locked door as a new
puzzle.

Most of the map is controlled by mission state.

My route is:

1. Enter the Hospital complex.
2. Work through the record areas tied to the **three main wings**.
3. Complete the local access or security interaction when a record area is
   still locked.
4. Read the Patient File information for the current run.
5. Enter that run's Patient Record code.
6. Finish all three Patient File objectives.
7. Switch from records to the marked cadavers.
8. Collect the required Tissue Samples.
9. Move toward the Quarantine phase.
10. Start the Courtyard ventilation.
11. Wait for ventilation to finish before entering the contaminated route.
12. Go upstairs when the Security Lockdown objective appears.
13. Complete **End Security Lockdown (0/2)**.
14. Return to the Laboratory.
15. Start the Bio Scanner and keep the Laboratory clear.
16. Follow the current extraction marker to the roof.

The early map is spread across several wings, so backtracking is normal.

What I avoid is **unnecessary** backtracking: returning to a later area before
the objective that unlocks it has changed.

<h2 id="patient-files">
  Start with the Patient Files in all three main wings
</h2>

The opening Hospital assignment is not one central records terminal.

My HUD sent the team after Patient Files tied to **three separate wings**.

That is the first major state check on the map.

While one of those Patient File objectives is still unfinished, I stay focused
on records rather than trying to reach Quarantine or the Laboratory.

Hospital can make a correct destination look inaccessible because a nearby
security step has not been completed yet.

If I reach a locked records door, I check the current objective before trying
the same entrance repeatedly.

My order is:

**record objective**

→ **required local access/security interaction**

→ **Patient File terminal**

→ **move to the next unfinished wing**

With a larger squad, this is also one of the few phases where splitting into
pairs saves real travel time.

I do not need four Responders following the same Patient File marker while two
other wings remain untouched.

I regroup once the map starts narrowing toward Quarantine.

<h2 id="patient-record-code">
  The Patient Record code changes between Hospital runs
</h2>

The Patient File terminals can require a six-digit numeric code.

I do **not** treat that number as a permanent Hospital password.

I saw different values in separate runs.

One record used:

**549927**

Another used:

**143043**

Once all required files are finished and the objective changes, I stop working
the records terminals and move into the Tissue Sample phase.

<h2 id="tissue-samples">

I then move through the marked Hospital areas and search cadavers for the
required Tissue Samples.

In one run, the team needed **four Tissue Samples**.

This is another stage where distance matters more than clearing every room.

If the next marked body is far across the complex, I move toward that marker.

I do not search every unmarked corpse I pass just because it can be interacted
with.

When the target area is crowded, I clear enough space to reach the marked body,
perform the search, then continue.

I do not try to make the entire ward permanently safe before touching the
objective.

The mission only needs the samples.

<h2 id="quarantine-ventilation">
  Start the Courtyard ventilation before entering Quarantine
</h2>

After the Tissue Sample phase, the route moves toward **Quarantine**.

The dangerous mistake is assuming that reaching the wing means it is ready to
enter.

It is not.

The contaminated atmosphere has to be handled first.

I follow the route back toward the **Courtyard ventilation system** and start
the process there.

<h2 id="security-lockdown">
  Ventilation and the Security Lockdown are separate progression gates
</h2>

This was the second major place I lost time.

Ventilation finished.

I reached the later Hospital area.

The Laboratory was still not ready.

The missing step was not another ventilation control.

The HUD sent me to the second floor with:

**End Security Lockdown (0/2)**

The objective itself tells me when this phase is complete.

That `0/2` counter is more reliable than assuming a single security room should
have opened everything.

<h2 id="avoid-contaminated-route">
  I go around if the direct route is still contaminated
</h2>

Hospital regularly lets me see where I want to go before the safest route is
actually open.

I do not treat visible destination distance as permission to cross a toxic
section.

In one run, a teammate cut through the contaminated area and started coughing
immediately afterward.

That was enough for me to stop using the gas as a shortcut.

If the direct path still looks unsafe, I take the longer interior route.

Hospital already contains enough progression gates that saving a few seconds is
not worth arriving at the next security objective with unnecessary damage.

This is especially important once the route has narrowed toward the final
Laboratory sequence.

I want the team arriving together, not one player waiting on the other side of
a hazardous shortcut.

<h2 id="morgue-shortcut">
  Use newly opened ladders and Morgue connections after the security phase
</h2>

Hospital changes its navigation as the mission advances.

A route that was blocked early can become the fastest route back later.

In one multiplayer run, a teammate reached an upper area and dropped a ladder
that created a much shorter connection back toward the **Morgue**.

I use that as a reminder to re-check:

- newly opened doors;
- dropped ladders;
- roof connections;
- wing-to-wing shortcuts

after a major security objective completes.

I do not automatically repeat the full path I used ten minutes earlier.

Hospital rewards noticing when the map has opened a new vertical connection.

<h2 id="hospital-stuck">
  What I check when Hospital stops progressing
</h2>

### The Patient File door is locked

I check whether a nearby access or security objective is still unfinished.

I do not keep testing the same locked door.

### A six-digit Patient Record code does not work

I reread the Patient File from **this run**.

Codes such as `549927` and `143043` came from different runs, so I do not treat
either as universal.

### I cannot find the next Tissue Sample

I confirm that I am following the marked cadaver objective rather than
searching every body in the building.

### Quarantine is still unsafe

I return to the Courtyard ventilation objective and wait for the process to
finish.

My run showed **1m54s** remaining shortly after it started.

### The Laboratory still says LOCKDOWN after ventilation

I check the second-floor security objective.

If it still says **End Security Lockdown (0/2)** or shows one remaining, I have
not finished both security points.

### I finished the Bio Scanner but cannot find extraction

I stop navigating toward an old roof from memory and read the current marker.

In my confirmed run, the destination was **Morgue Wing Roof**.

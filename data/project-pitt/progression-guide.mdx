<GuideQuickAnswer title="Quick Answer">
I progress through Project P.I.T.T. by following the **newest product or clear progression signal**, not by trying to perfect every factory before I move on.

My route is:

**Ducks**

→ unlock simple Duck automation

→ **Cash Registers**

→ automate enough to keep progression moving

→ **Phase 3**

→ rebuild around **Piñatas**

→ **Phase 4**

→ unlock **Anomalies**

→ when I deliberately want the hidden route, finish the camera / fuse path

→ reach the **200 kg platform**

→ solve the **0% gate**

→ continue into the **Secret Ending route**

My rule is:

**progress first → automate the current bottleneck → stop overbuilding → move on when the next product or phase opens**
</GuideQuickAnswer>

<h2 id="start-with-ducks">
  I start with Ducks and keep the opening disposable
</h2>

The opening is simple.

I make Ducks, get them into the Pit, and use that income to unlock the basic tools and movement upgrades that make the room less manual.

I do not spend the first phase designing the factory I expect to use for the rest of the game.

I only need enough handling to stop making one-product trips and enough income to reach the first useful automation unlocks.

Once the Automatic Duck Machine becomes available, I let it keep the economy moving while I work on progression.

If the Duck route itself becomes the problem, I use the <Link href="/project-pitt/duck-automation">Duck Automation guide</Link>.

If I am not sure whether I need more airflow, containment, or a different catch, I use the <Link href="/project-pitt/automation-layouts">Automation Layout Helper</Link> instead of turning this progression page into a layout guide.

<h2 id="duck-to-cash">
  I move to Cash Registers before the Duck factory is perfect
</h2>

The first important progression habit is learning when to leave a working product alone.

Once Cash Registers become the active next product, I start using them.

I do not keep feeding Ducks just because the Duck side is comfortable and familiar.

Cash Registers change the transport problem enough that I treat them as a new stage, not as a larger Duck.

My goal is:

**get Cash Registers producing**

→ **get them into the Pit reliably**

→ **unlock their automation**

→ **keep enough income flowing to reach the next phase**

I do not need the cleanest possible shared factory before I move on.

For the product-specific route, I use the <Link href="/project-pitt/cash-register-automation">Cash Register Automation guide</Link>.

<h2 id="before-phase-3">
  I stop overbuilding when Phase 3 is close
</h2>

This is one of the biggest time-saving decisions in the run.

Before Phase 3, it is easy to keep adding Panels, Fans, and increasingly complicated shared routes because the factory finally has enough money to support them.

I stop once the current setup is reliable enough.

Phase 3 changes the room and can destroy part of the existing factory.

That means I do not spend another long session making an older line beautiful when the game is about to change the warehouse.

My stop condition before Phase 3 is:

**income is moving**

**the current product reaches the Pit**

**I am not constantly rescuing the line by hand**

Once those are true, I take the progression.

<h2 id="phase-3">
  Phase 3 is the rebuild point and Piñatas become the new priority
</h2>

Phase 3 is where I stop thinking of the factory as one permanent construction.

The room changes.

Old automation may be damaged.

Piñatas unlock.

I do not try to restore every old Panel exactly where it was.

I look at what the new stage needs.

Piñatas behave differently from the earlier products because transport, breaking, and Candy containment become separate problems.

That detail belongs in the <Link href="/project-pitt/pinata-automation">Piñata Automation guide</Link>.

For progression, all I need to know is:

**Phase 3 happens**

→ **the old factory may no longer be worth preserving**

→ **Piñatas are now the product I build around**

<h2 id="phase-4">
  Phase 4 is when Anomalies become the late-game product
</h2>

Later progression reaches Phase 4 and unlocks Anomalies.

That is the next major product transition.

By this point I already have Duck, Cash Register, and Piñata production behind me, so I stop treating every older line as equally important.

I ask what I am trying to do next.

If I want more production, I build enough Anomaly supply to keep the late-game economy moving.

If I am preparing for hidden progression, I keep some Anomalies available instead of automatically feeding everything into the Pit.

For the recipe, workbench, Intern Substitute, supply balancing, and Anomaly farming, I use the <Link href="/project-pitt/anomaly-guide">Anomaly Guide</Link>.

This progression page only owns the timing:

**Phase 4 → Anomalies unlock → Anomalies become relevant to the late-game route**

<h2 id="upper-route">
  I treat the upper route as a deliberate hidden branch
</h2>

The upper catwalk and hidden objects are visible before I actually need to chase them.

I do not abandon the current product line every time I notice something above the factory.

When I deliberately decide to pursue the hidden route, I follow the upper-area sequence.

The important order is:

**deal with the cameras**

→ **reach the upper area**

→ **bring the three fuses to their sockets**

→ **place all three**

Two fuses are not the end.

Those are stronger progression cues than the urge to keep improving an old layout.

<h2 id="hidden-gate">
  When the hidden gate opens, the run becomes a separate ending route
</h2>

The 200 kg / 0% sequence eventually opens the hidden gate.

That is another clean boundary.

Before the gate opens, I am still solving access.

After the gate opens, I am no longer doing ordinary factory progression.

I am following a sequence of hidden minigames and puzzle tools.

At that point I switch to the <Link href="/project-pitt/secret-ending">Secret Ending guide</Link>.

I do not mix the clone room, mining layers, UV clues, Access Card, or elevator code into this page.

Those belong to the ending route.

<h2 id="when-i-go-back">
  I only revisit an old product when a new unlock changes the answer
</h2>

The easiest way for me to waste time is rebuilding the same problem with the same tools.

I use a stricter rule.

I go back to an old layout when:

**a new tool removes the old bottleneck**

**the room itself changed**

**the older line is now hurting the current product**

**I need that line for a late-game goal**

I do not go back just because I can make the layout prettier.

That keeps the run moving forward instead of turning every phase into a permanent construction project.

<h2 id="my-route">
  The route I would use again from a fresh save
</h2>

My full progression map is:

**feed Ducks manually**

→ **unlock Duck automation**

→ **move to Cash Registers**

→ **automate enough to keep income moving**

→ **stop overbuilding before Phase 3**

→ **enter Phase 3**

→ **build around Piñatas**

→ **reach Phase 4**

→ **unlock Anomalies**

→ **decide when I want the hidden branch**

→ **cameras**

→ **three fuses**

→ **upper route opens**

→ **200 kg platform**

→ **0% gate**

→ **hidden gate opens**

→ **Secret Ending route**

The important part is not memorizing every tool purchase.

It is knowing when a stage has done enough.

My progression rule stays the same from the first Duck to the hidden route:

**follow the newest clear objective**

→ **automate only enough to remove the current bottleneck**

→ **stop polishing once progression is available**

→ **move on**
